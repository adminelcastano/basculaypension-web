# Báscula y Pensión El Castaño

Página web de basculaypension.com. Es un solo archivo, `index.html`, sin compilación.

## Cambiar datos del negocio

Al final de `index.html` está el bloque `NEGOCIO` con WhatsApp, teléfono, correo, dirección, enlace de Google Maps y horarios. Al cambiar un valor ahí, la página se actualiza en todos los lugares donde aparece. Los campos vacíos (tarifas, capacidad, plazo de factura) no se muestran.

## Publicación

Cloudflare Pages publica automáticamente cada cambio en la rama `main`.
